# Auto-Diffrentiation-Engine
An Auto-Differentiation Engine that computes gradients for a network of mathematical expressions. This project implements the core functionality needed to perform automatic differentiation, enabling backpropagation in computational graphs.

## Features

Automatic Gradient Computation: Efficiently calculates gradients for scalar and vector-valued outputs.\
Support for Computational Graphs: Handles complex mathematical networks with multiple dependencies.\
Custom Backward Pass: Propagates gradients through the graph to compute partial derivatives.
